SportLife — учебный сайт о спорте
==================================

Файлы:
- index.html             главная страница с кнопкой «Подробнее», динамическими карточками и Bootstrap modal
- about.html             страница «О проекте»
- contacts.html          страница «Контакты» с проверкой формы
- style.css              оформление и адаптивная вёрстка
- script.js              мобильное меню, кнопка, проверка формы и fetch
- data/projects.json     данные для динамических карточек

Что реализовано для задания по JavaScript:
1. Кнопка показывает и скрывает дополнительный текст.
2. Форма проверяет имя, email и сообщение без перезагрузки страницы.
3. Карточки спортивных направлений создаются из JSON-файла через fetch().
4. Подключён Bootstrap 5 и используется компонент Modal.
5. JavaScript подключён отдельным файлом script.js с атрибутом defer.

Как проверить:
1. Распакуйте архив.
2. Для корректной проверки fetch откройте сайт через GitHub Pages или локальный сервер (например, Live Server), а не через file://.
3. Проверьте кнопку «Подробнее», карточки на главной странице, модальное окно и форму контактов.
4. Для публикации загрузите все файлы и папку data в корень репозитория GitHub.
5. В GitHub откройте Settings → Pages. Выберите Deploy from a branch, Branch: main, Folder: /(root), затем Save.
6. После публикации откройте сайт и проверьте Console в инструментах разработчика.

Важно:
- Изображения, шрифт и Bootstrap загружаются из интернета.
- Форма демонстрационная: без серверной части она проверяет данные и показывает сообщение, но не отправляет их.
- Файл data/projects.json должен быть опубликован вместе с сайтом, иначе fetch не сможет загрузить карточки.
