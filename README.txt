SportLife — учебный сайт о спорте
==================================

Файлы:
- index.html    главная страница
- about.html    страница «О проекте»
- contacts.html страница «Контакты»
- style.css     оформление и адаптивная вёрстка
- script.js     мобильное меню и демонстрационная форма

Как проверить:
1. Распакуйте архив.
2. Откройте index.html в браузере.
3. Для публикации загрузите все файлы в корень репозитория GitHub.
4. В GitHub откройте Settings → Pages.
5. В разделе Build and deployment выберите Deploy from a branch,
   Branch: main, Folder: /(root), затем Save.

Важно:
- Изображения и шрифт загружаются из интернета.
- Контактная форма демонстрационная: без серверной части она не отправляет сообщения.
